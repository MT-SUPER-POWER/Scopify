## 发起请求

1. 打开接口目录中的任一分类页面。
2. 在接口卡片顶部选择 `Scopify Vercel 后端` 或本地后端。
3. 展开 `Query`，填写必选参数。
4. 点击 `Send`，在页面中查看真实状态码、响应头和 JSON 返回值。

无需登录的搜索、歌曲详情和公开歌单接口可以直接测试。需要登录的接口可填写 `cookie` 参数，但不要在共享设备或公开文档环境中使用真实凭据。

## 安全边界

- 请求由浏览器直接发送到选择的 Netease API Server URL。
- 文档站不保存 Cookie，也没有可转发任意目标的开放代理。
- 写操作会真实影响账号数据，发送前必须确认接口语义和参数。
- 返回结构以当前后端和网易云上游实际响应为准。
