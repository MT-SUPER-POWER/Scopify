Netease API 是 Scopify 对 `Netease Cloud Music API Enhanced` 的独立部署。接口目录从后端真实模块生成，并通过 Fumadocs OpenAPI 组件展示参数、响应模型、代码示例与请求面板。

## 服务地址

| 环境   | Base URL                         |
| ------ | -------------------------------- |
| Vercel | `https://scopify-api.vercel.app` |
| 本地   | `http://127.0.0.1:3838`          |

## 实际请求

接口页顶部的 `Send` 按钮会直接向所选 Server URL 发起请求，并在页面内展示当前响应状态、响应头与 JSON 返回值。Vercel 后端已允许文档站跨域访问，因此无需经过开放代理。

<Callout type="warn" title="真实操作与登录凭据">
  请求会真实到达后端。收藏、关注、删除、签到等接口可能改变网易云账号状态；发送前请检查接口语义。不要在公共环境、截图或提交记录中填写真实 Cookie。
</Callout>

## 文档完整度

路由以 `repo/backend/api-enhanced/module/` 中的真实模块为准；标题、说明、必选参数与示例优先复用 `public/docs/home.md`。响应结构不明确时保留通用 JSON 模型，实际结果以请求面板返回为准。
