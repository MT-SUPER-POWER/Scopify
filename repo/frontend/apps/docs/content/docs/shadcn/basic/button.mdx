## 使用

```tsx
import { Button } from "@scopify/ui/shadcn/components/button";

<Button variant="outline" size="sm">
  播放
</Button>;
```

支持 `default`、`destructive`、`outline`、`secondary`、`ghost`、`link` 六种视觉变体，以及文本与图标尺寸。
