## 系统组成

```text
Scopify/
├── repo/frontend/apps/web        # Next.js Web 与 Desktop Renderer
├── repo/frontend/apps/desktop    # Electron 主进程与 Preload
├── repo/frontend/apps/docs       # Scopify Docs
├── repo/frontend/packages/ui     # 共享 UI 资产
├── repo/frontend/packages/desktop-contract
└── repo/backend/api-enhanced     # 独立后端服务
```

## 核心边界

- Web 使用 Next.js App Router、Zustand，并通过 HTTP 访问独立后端。
- Desktop 是 Electron Host，不反向导入 Web 源码。
- `desktop-contract` 只保存 Web 与 Desktop 之间可版本化的纯 TypeScript 契约。
- `@scopify/ui` 只提供共享视觉基础与通用交互，不依赖路由、Store、API 或业务 i18n。

## 编排

根目录通过 Bun Workspaces 管理依赖，通过 Turborepo 编排构建、类型检查、测试和开发服务。
