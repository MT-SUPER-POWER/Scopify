## 播放与队列

### 播放控制

底部播放栏贯穿主要页面，提供喜欢、评论、上一首、播放暂停、下一首、循环、进度、音量和全屏等常用控制。播放模式、当前音质、输出设备和待播队列也从这里进入，不需要离开正在浏览的内容。

### 待播与上下文

| 能力 | 当前用途 |
| --- | --- |
| 播放控制 | 调整进度、音量、播放暂停与上下曲 |
| 播放模式 | 切换随机、顺序、单曲循环等模式 |
| 待播队列 | 查看接下来播放的曲目并管理播放顺序 |
| 播放上下文 | 快速进入评论、歌词、音频设置和全屏舞台 |

## 歌词与 Folia

### Folia 歌词舞台

歌词体验由动态舞台和控制面板组成。舞台负责呈现当前歌曲、歌词动画和背景视觉；控制面板负责音量、音质、均衡器、ReplayGain、歌词来源、歌词匹配和时间轴偏移。需要更细的调整时，可以继续进入 Folia 设置。

## 音频体验

### 音质选择

Scopify 可以针对播放环境选择标准、较高、无损、Hi-Res、沉浸声和空间音频等可用音质。

<figure>
  <img className="rounded-xl border" src={audioQualityScreenshot.src} alt="Scopify 播放音质选择面板" />
  <figcaption>根据账号、曲目和设备选择可用音质。</figcaption>
</figure>

### 均衡器与响度

均衡器提供 10 个频段、预设与自动余量，并补充低切、高切、驱动、颗粒、磁带抖晃、黑胶噪声、立体声宽度、混响和低频冲击等效果。

<figure>
  <img className="rounded-xl border" src={audioEqualizerScreenshot.src} alt="Scopify 十段均衡器与声音效果" />
  <figcaption>均衡器和声音效果可以按当前聆听环境调整。</figcaption>
</figure>

ReplayGain 支持按曲目或专辑统一响度，适合在跨专辑播放和连续听歌时减少音量突变。

## 桌面端集成

### 桌面歌词

Electron 桌面端在共享 Web 界面之外提供系统级能力，包括桌面歌词、窗口置顶与穿透、Discord Rich Presence、客户端更新、本地后端配置以及日志诊断。桌面歌词可独立于主窗口显示，Discord 状态则用于同步当前播放信息。
