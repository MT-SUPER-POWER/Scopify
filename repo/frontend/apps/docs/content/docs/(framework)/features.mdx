Scopify 不只是一个接口播放器。产品围绕音乐浏览、搜索、播放队列、沉浸歌词和桌面呈现形成完整体验。

## 核心页面

- 主页面：承载推荐内容、快捷入口与当前用户上下文。
- 歌单页面：展示歌单资料、歌曲列表与播放入口。
- 用户页面：展示用户资料、收藏与社交信息。
- 评论页面：浏览歌曲、歌单等资源的评论内容。

## 搜索体验

搜索能力包括搜索模态框、常驻搜索栏和完整结果页面。不同入口共享搜索上下文，让用户可以从快速发现自然过渡到分类结果浏览。

## 歌词舞台

歌词是 Scopify 最具辨识度的体验之一：

- 歌词随播放进度动态呈现。
- 提供歌词效果控制与样式编辑。
- 支持可视化主题编辑。
- 支持全屏歌词与桌面音乐呈现。
- 部分完整播放舞台与桌面歌词能力来自 Folia 源码快照。
