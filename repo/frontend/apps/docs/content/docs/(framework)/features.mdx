## 内容发现

### 首页与推荐

首页把每日推荐、个性化歌单、活动内容、播客声音和推荐歌手放在一条连续的浏览路径中。用户可以先试听或查看内容，再进入歌单、专辑和歌手页面继续探索。

  <figcaption>首页同时承担内容推荐、快速播放和继续浏览的入口。</figcaption>
</figure>

### 歌单管理与 Lattice 视图

歌单与专辑的操作区可以把当前页面的歌曲切换为 Lattice 拼贴视图：一面 Folia 风格的海报墙，支持拖动浏览、封面展开、直接播放和定位当前歌曲，返回列表时保留搜索与滚动位置。

<figure>
  <img className="rounded-xl border" src={latticeScreenshot.src} alt="Scopify 歌单 Lattice 拼贴视图" />
  <figcaption>Lattice 把歌单变成可以拖动浏览的海报墙。</figcaption>
</figure>

列表本身支持完整的整理操作：

| 操作 | 说明 |
| --- | --- |
| 多选 | `Shift` 区间连选，`Ctrl` / `Cmd` 自由多选，`Esc` 清空选择 |
| 拖拽排序 | 自建歌单曲目与侧栏歌单可直接拖动调整顺序 |
| 拖拽点赞 | 将歌曲拖到侧栏「我喜欢的音乐」即可一键喜欢 |
| 右键菜单 | 多选后可批量播放、加入歌单；单曲菜单提供「接着听相似歌曲」 |
| 收藏他人歌单 | 在歌单操作区直接收藏 |

### 私人 FM 与电台

私人 FM 作为动态歌单进入通用歌单详情页，沿用普通歌单的曲目计数与操作区。登录后也可以从侧边栏的「私人电台」直接进入沉浸播放，队列接近末尾时会自动补充歌曲。

场景与模式（默认、熟悉、探索、拼图，以及情绪、场景、曲风、语种）收纳在 PlayBar 的控制面板中，只在 FM 播放时出现。私人 FM 歌单里的歌曲可通过右键菜单选择「不喜欢 / 减少推荐」，反馈会进入既有的负反馈流程，不影响普通歌单。

## 播放与队列

### 播放控制

底部播放栏贯穿主要页面，提供喜欢、评论、上一首、播放暂停、下一首、循环、进度、音量和全屏等常用控制。播放模式、当前音质、输出设备和待播队列也从这里进入，不需要离开正在浏览的内容。

### 待播与上下文

| 能力 | 当前用途 |
| --- | --- |
| 播放控制 | 调整进度、音量、播放暂停与上下曲 |
| 播放模式 | 切换随机、顺序、单曲循环等模式 |
| 待播队列 | 查看接下来播放的曲目并管理播放顺序 |
| 播放上下文 | 快速进入评论、歌词、音频设置和全屏舞台 |

### 歌词模式与副字幕

Folia 提供 14 种歌词动画。除商籁、凝彩、莫奈、时计等模式外，「档案」模式把歌曲信息、歌词序号、逐词读取和时间码排成科研档案版式，并配有莱茵档案背景。

副字幕支持「罗马音 + 翻译」双行显示，商籁、时计和莫奈都已适配。歌词背景还可以叠加本地视频层，Sora 背景提供纯色空白选项。

完整播放舞台与桌面歌词的部分能力来自 [Folia](https://github.com/chthollyphile/folia-major/tree/main) 源码快照，并在 Scopify 中继续适配。

### 音质选择

Scopify 可以针对播放环境选择标准、较高、无损、Hi-Res、沉浸声和空间音频等可用音质。

### 均衡器与响度

均衡器提供 10 个频段、预设与自动余量，并补充低切、高切、驱动、颗粒、磁带抖晃、黑胶噪声、立体声宽度、混响和低频冲击等效果。

<figure>
  <img className="rounded-xl border" src={audioEqualizerScreenshot.src} alt="Scopify 十段均衡器与声音效果" />

ReplayGain 支持按曲目或专辑统一响度，适合在跨专辑播放和连续听歌时减少音量突变。

## 社交与通知

### 动态与乐迷团

## 桌面端集成

### 桌面歌词

Electron 桌面端在共享 Web 界面之外提供系统级能力，包括桌面歌词、窗口置顶与穿透、Discord Rich Presence、客户端更新、本地后端配置以及日志诊断。桌面歌词可独立于主窗口显示，Discord 状态则用于同步当前播放信息。

<figure>
  <img className="rounded-xl border" src={desktopLyricScreenshot.src} alt="Scopify 桌面歌词和全屏音乐效果" />
  <figcaption>桌面歌词把当前播放内容延伸到主窗口之外。</figcaption>
</figure>

### 桌面壁纸与托盘

「桌面音乐壁纸」把歌词舞台铺满桌面，在多显示器环境下覆盖主窗口所在的显示器。系统托盘菜单提供「桌面动态壁纸」与「悬浮控制器」两个独立开关，状态与主窗口双向同步，壁纸也有独立快捷键（默认 `Ctrl+Alt+P`）。

### 音频输出与系统媒体控制

PlayBar 可直接切换音频输出设备（`Ctrl/Cmd+Alt+O` 打开面板）。播放信息同步到系统媒体控制（SMTC / MediaSession），Windows 版本可使用原生音频 Host。

### MCP 播放控制

桌面端提供仅监听本机回环地址的 Streamable HTTP MCP 服务，让支持 MCP 的客户端读取播放状态并控制播放。设置页可复制标准 `mcpServers` 配置、测试连接并重新生成凭据，旧令牌立即失效；读取与控制共 9 项能力可分别开启。完整说明见 [MCP 播放控制](/docs/mcp)。
