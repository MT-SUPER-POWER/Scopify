---

Scopify 是一个采用 Spotify 风格界面、连接网易云音乐服务的音乐播放器。项目同时提供 Web 与 Electron 桌面体验，并围绕歌词舞台、个性化主题和桌面播放能力持续演进。

当前主要保证 Windows 桌面端适配；Web 与后端保持独立部署，桌面端可以使用随安装包提供的本地后端，也可以连接远程服务。

## 项目定位

| 维度 | 当前定位 |
| --- | --- |
| 产品 | Spotify 风格的网易云音乐客户端 |
| 运行形态 | Web 应用与 Electron 桌面客户端 |
| 前端 | Next.js App Router、React、TypeScript |
| 桌面 | Electron Host + Web Renderer |
| 后端 | 独立部署的 NetEase API Enhanced |
| 包管理与编排 | Bun Workspaces + Turborepo |
| 平台状态 | 目前重点保证 Windows 体验 |
