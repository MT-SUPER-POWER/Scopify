## 桌面歌词

Electron 桌面端在共享 Web 界面之外提供系统级能力，包括桌面歌词、窗口置顶与穿透、Discord Rich Presence、客户端更新、本地后端配置以及日志诊断。桌面歌词可独立于主窗口显示，Discord 状态则用于同步当前播放信息。

## 桌面壁纸与托盘

「桌面音乐壁纸」把歌词舞台铺满桌面，在多显示器环境下覆盖主窗口所在的显示器。系统托盘菜单提供「桌面动态壁纸」与「悬浮控制器」两个独立开关，状态与主窗口双向同步，壁纸也有独立快捷键（默认 `Ctrl+Alt+P`）。

## 灵动岛与任务栏歌词

灵动岛将封面与歌词放在可拖动的胶囊中，靠近屏幕顶边时自动吸附，可以调整换行动画、大小、翻译与置顶。Windows 任务栏歌词把当前歌词嵌入任务栏空白区域，支持显示位置、双行歌词、封面与文字样式设置。

右键系统托盘中的 Scopify 图标，即可在快捷面板中分别切换「桌面歌词」「灵动岛」和「任务栏歌词」。桌面歌词开启后还会出现锁定开关；任务栏歌词入口仅在 Windows 原生模块可用时显示。动画、字号与显示位置等细项位于 **设置 → 桌面端**。

## 音频输出与系统媒体控制

PlayBar 可直接切换音频输出设备（`Ctrl/Cmd+Alt+O` 打开面板）。播放信息同步到系统媒体控制（SMTC / MediaSession），Windows 版本可使用原生音频 Host。

<figure>
  <img className="h-auto w-full rounded-xl border" src={audioOutputScreenshot.src} alt="Scopify 播放栏的音频输出设备选择面板" />
  <figcaption>在播放栏选择输出设备，也可以刷新设备列表。</figcaption>
</figure>

## MCP 播放控制

桌面端提供仅监听本机回环地址的 Streamable HTTP MCP 服务，让支持 MCP 的客户端读取播放状态并控制播放。设置页可复制标准 `mcpServers` 配置、测试连接并重新生成凭据，旧令牌立即失效；读取与控制共 9 项能力可分别开启。完整说明见 [MCP 播放控制](/docs/mcp)。
