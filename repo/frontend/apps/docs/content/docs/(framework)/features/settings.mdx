## 外观与主题

外观设置分为「精选主题」和「我的主题」。主题保存颜色、强度和渐变范围，可以创建、命名、另存、批量管理；每日轮换允许按 24 小时时间带为不同时段指定主题。背景与字幕歌词也在这里调整，字幕歌词提供胶囊排版、主副行、淡入 / 浮入 / 逐字等效果的预览工作台，并支持命名样式方案库。
