## Folia 歌词舞台

歌词体验由动态舞台和控制面板组成。舞台负责呈现当前歌曲、歌词动画和背景视觉；控制面板负责音量、音质、均衡器、ReplayGain、歌词来源、歌词匹配和时间轴偏移。需要更细的调整时，可以继续进入 Folia 设置。

默认按 `Ctrl + Alt + ,`（macOS 为 `Cmd + Option + ,`）可打开或关闭舞台控制面板；如果歌词舞台尚未打开，会先进入舞台并展开面板。按 `Esc` 时先关闭控制面板，再次按下才退出舞台；更上层的设置或弹窗会先处理退出操作。

## 歌词动画

Folia 提供 17 种歌词动画，在控制面板的「歌词样式」里切换，也可以用上一个 / 下一个逐个试。下面按由静到闹排列：越往后画面越满、镜头越多，对显卡的要求也越高。

### 安静排版

适合长时间挂着听，或配合桌面歌词与专注场景。

- **静止**：不做动画，只随播放切换当前行，资源占用最低。
- **流光**：经典逐字流光，可调逐字旋转与整行呼吸浮动。
- **云阶**：歌词按语义分块错落成台阶，可显示引导线。
- **倾诉**：随机分行与斜体强调，像在耳边说话。
- **心象**：大字号排版与光束，可调行宽压缩、动势和发光。

### 叙事构图

歌词之外加入构图、道具或版式，适合想「看」一首歌的时候。

- **浮名**：打印方块与镜头追焦，可选逐步或平滑追焦。
- **回环**：歌词沿倾斜的椭圆轨道绕行，当前句放大。
- **档案**：把歌曲信息、歌词序号、逐词读取和时间码排成档案版式，可搭配莱茵背景。
- **群唱**：把歌词改写成一段群聊，头像与表情包都可以换成自己的。
- **时计**：钟表表盘与齿轮，歌词随指针一格格走过。
- **莫奈**：海报式版面，配右侧肖像、关键字着色与底部频谱。

### 沉浸场景

用 WebGL 搭出完整场景，镜头随歌词移动；建议在性能较好的设备上使用。

- **雾笺**：雨夜公交起雾的车窗上，指尖按笔顺写出歌词，雾气慢慢回拢。
- **镜台**：三维点云或长廊中的歌词舞台，可调粒子、几何与音频响应。
- **町景**：便利店街角、加油站、九龙酒吧等微缩街景，当前句亮在 LED 屏上；场景、时段与天气都可设为自动，也能拖动视角。

### 歌词 PV

日系歌词 PV 风格的「导演」模式，按歌词时间轴自动分镜，是最绚烂的一组。

- **商籁**：MG 动态构图与转场，可开后期处理（颗粒、色散、半调等）；建议搭配「空」等偏静态背景。
- **凝彩**：色块拼贴构图，可导入自己的图片作为拼贴素材。
- **花火**：歌词落在明亮的色块上，烟花与 MG 贴纸沿字词绽开，镜头像放烟火一样一镜接一镜地上升。

<Callout title="不知道选哪个？">
  打开「每首歌随机切换歌词动画」，再在随机池里勾选喜欢的几种；每首歌会从池子里挑一种，不满意可以点「换一种」。
</Callout>

## 背景

歌词动画背后是一层可单独设置的背景：

- **通用**：默认背景，可把歌曲封面的色彩叠加进去。
- **莫奈**：用封面或自定义图片做水洗、漂移与模糊处理。
- **漫游**：把封面或自定义图片转换成像素画，并可叠加毛玻璃、纸纹、半调等效果。
- **隐现**：封面取色的像素与流体着色器，对音频有更大范围的速度响应。
- **嵌入**：把一个网页当作背景（部分网站禁止被嵌入，可能无法显示）。
- **空**：Sora 星空，或纯色空白；纯色模式夜间纯黑、日间纯白，适合搭配视频层。
- **莱茵**：档案盒随音乐起伏，切歌时交接当前档案。

任意背景上还可以叠加一层**本地视频或视频 URL**：静音播放，跟随音乐播放、暂停和跳转，可调不透明度和填充方式。

## 副字幕与和声

副字幕可显示翻译、罗马音或「罗马音 + 翻译」双行，商籁、时计和莫奈都已适配。歌词带和声时，可以单独显示和声行并给它加背景。字号、字体与副字幕字体都能单独设置，也可以上传自定义字体。

## 歌词对不上时

- **全局歌词偏移**：一边听歌一边把歌词对准声音，确认后才替换当前偏移值，可随时回到零点。
- **时间轴偏移与歌词匹配**：在舞台控制面板里调整；匹配错了歌词，也可以在这里切换歌词来源。

## 导出视频

在全局设置里可以把当前歌词舞台连同正在播放的音频录成 MP4 或 WebM，支持从当前位置或从歌曲开头录制。视频层使用的本地视频不参与导出。

## 性能建议

沉浸场景与歌词 PV 两组使用 WebGL 渲染。如果出现掉帧，可以：

- 在对应模式的设置里调低渲染质量或贴图分辨率，关闭后期处理；
- 换成「空」或「通用」等较轻的背景；
- 换回安静排版组的动画，或直接使用「静止」。

完整播放舞台与桌面歌词的部分能力来自 [Folia](https://github.com/chthollyphile/folia-major/tree/main) 源码快照，并在 Scopify 中继续适配。
