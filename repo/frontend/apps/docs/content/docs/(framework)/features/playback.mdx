## 播放控制

底部播放栏贯穿主要页面，提供喜欢、评论、上一首、播放暂停、下一首、循环、进度、音量和全屏等常用控制。播放模式、当前音质、输出设备和待播队列也从这里进入，不需要离开正在浏览的内容。

## 歌曲资料与 MV

打开播放栏的「正在播放」面板，或按 `Ctrl + Alt + B`（macOS 为 `Cmd + Option + B`），可以在「正在播放」「歌词」「队列」之间切换。面板展示当前歌曲、歌词预览、艺人及相关内容；歌词视图支持点击歌词跳转，宽窗口下还可以直接查看队列。

<figure>
  <img className="h-auto w-full rounded-xl border" src={nowPlayingPanelScreenshot.src} alt="正在播放面板，顶部可切换正在播放、歌词和队列" />
  <figcaption>在右侧面板查看当前歌曲与歌词，不必离开当前页面。</figcaption>
</figure>

向下浏览面板，可以查看当前歌曲的音乐百科和乐谱；点击卡片上的「查看全部」展开完整内容。乐谱预览需要登录，具体谱页是否可用取决于内容权限；没有资料时会显示空状态。

## MV 播放与评论

有 MV 的歌曲可以从正在播放面板进入 MV 播放页，也可以从 [MV 搜索](/docs/features/search) 打开。播放页将视频、歌曲信息与互动操作组合在一起，提供画质、倍速、自动续播、剧场模式、网页全屏和全屏。歌单和专辑也可进入 MV 预览，逐首浏览相关视频。

### 播放器设置

点击视频右下角的齿轮打开「播放器设置」，统一调整画质、播放速度和「自动播放下一个」。画质支持自动选择与视频提供的清晰度，切换时保留进度；开启自动续播后，播完会接着播放可用的下一支相似 MV。

<figure>
  <img className="h-auto w-full rounded-xl border" src={mvSettingsScreenshot.src} alt="完整客户端窗口，MV 播放器设置展开画质、播放速度和自动播放下一个" />
  <figcaption>播放器设置集中在齿轮菜单中，不必离开视频。</figcaption>
</figure>

播放速度提供 0.5×、0.75×、正常、1.25×、1.5×、1.75× 和 2×。

<figure>
  <img className="h-auto w-full rounded-xl border" src={mvSpeedScreenshot.src} alt="完整客户端窗口，MV 播放速度菜单展示 0.5 倍至 2 倍选项" />
  <figcaption>展开播放速度，按观看习惯选择倍速。</figcaption>
</figure>

### 剧场模式与底部播放栏

点击齿轮旁的「剧场模式」按钮展开菜单，或按 `T` 直接切换。开启后视频横跨内容区域，详情与相似 MV 移到下方，并默认隐藏应用底部播放栏，为画面留出更多空间；视频自身的进度、音量和播放控制仍然保留。

<figure>
  <img className="h-auto w-full rounded-xl border" src={mvTheaterScreenshot.src} alt="MV 剧场模式，宽幅播放器横跨内容区域" />
  <figcaption>同一画面的剧场模式：播放器放大，底部播放栏隐藏，顶部导航与左侧栏仍可使用。</figcaption>
</figure>

在剧场模式菜单中打开「显示播放条」，可以保留底部歌曲播放栏；关闭则重新收起。退出剧场模式或离开 MV 页面时，底部播放栏恢复显示。

播放页下方可浏览评论、切换排序、点赞和回复，也可进入完整评论页；相似 MV 在独立区域展示，加载失败时可以重试。

<figure>
  <img className="h-auto w-full rounded-xl border" src={mvCommentsScreenshot.src} alt="MV 页面中的评论列表、排序、点赞与回复入口" />
  <figcaption>评论直接接在视频信息下方，也可进入完整评论页。</figcaption>
</figure>

在 MV 播放器中，`Space` / `K` 播放或暂停，`J` / `L` 后退或前进 10 秒，`←` / `→` 调整 5 秒，`↑` / `↓` 调整音量，`M` 静音；`T` 切换剧场模式，`W` 切换网页全屏，`F` 切换全屏，`Esc` 关闭展开的菜单或退出网页全屏。输入评论时不会触发这些单键快捷键。
