## 动态与乐迷团

社交页提供关注动态与乐迷团笔记。乐迷团笔记以卡片瀑布流展示，点击卡片可在浮层中查看详情；可以按加入的团筛选，聚合动态会标明来源。动态支持文字与音乐分享、转发、点赞、评论回复和删除自己的内容；音乐附件复用播放器与队列，可以直接播放。同时提供关注 / 粉丝列表和用户搜索。

## 私信

私信位于好友图标下，独立显示未读会话，支持历史消息、文字与表情，以及歌曲、专辑、歌单分享卡片，并提供一键全部已读。

<figure>
  <img className="h-auto w-full rounded-xl border" src={privateMessagesScreenshot.src} alt="登录后的私信会话，展示歌手消息、专辑卡片与消息输入框" />
  <figcaption>从右上角进入私信，查看历史消息与音乐卡片，通过底部输入框和表情入口回复。</figcaption>
</figure>

## 通知中心

铃铛汇总互动、报告与更新通知，按日期分组，支持未读筛选和显式已读。桌面端可通过通知设置配置免打扰与隐私预览，系统提醒点击后直接回到对应内容。
