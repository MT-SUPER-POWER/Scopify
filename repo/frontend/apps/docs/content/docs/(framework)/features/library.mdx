## 个人音乐库

登录后的个人内容汇集在音乐库中，包括喜欢的音乐、最近播放、播客、收藏和自建歌单。列表保留歌曲音质、会员标识、专辑、发布时间、喜欢状态和时长等信息，并提供播放、随机播放和列表内搜索。

「我的云盘」集中管理网易云音乐云盘中的歌曲，支持播放、上传、匹配、下载和删除。对于网易云没有歌词的云盘歌曲，播放器也可以显示上传文件中自带的歌词。

## 听歌足迹

最近播放页提供「听歌足迹」入口。足迹页可以切换周、月、年报告，展示听歌时长、歌曲数、活跃天数、高频歌曲、钟爱歌手与偏爱风格；周报支持回看过去 16 周。个人主页也会显示累计听歌时长，通知中心的周报、年报通知会直接跳转到对应周期。
