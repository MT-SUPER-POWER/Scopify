Scopify 的快捷键分为播放控制、界面操作和快捷键管理三组。默认快捷键会根据当前系统显示为 `Ctrl` 或 `Cmd`；在 macOS 上，文档中的 `Ctrl` 位置对应 `Cmd`。

快捷键只在当前焦点允许时执行：搜索框、文本框和其他可编辑控件会优先保留自己的输入行为。播放控制器、搜索弹窗、命令面板和快捷键帮助面板打开时，也会根据当前作用域处理按键。

## 快捷键总览

### 播放控制

| 操作 | Windows / Linux | macOS | 说明 |
| --- | --- | --- | --- |
| 播放 / 暂停 | `Space` | `Space` | 切换当前播放状态。 |
| 上一首 | `Ctrl + ←` | `Cmd + ←` | 切换到上一首歌曲。 |
| 下一首 | `Ctrl + →` | `Cmd + →` | 切换到下一首歌曲。 |
| 增大音量 | `Ctrl + ↑` | `Cmd + ↑` | 每次增加 5 个音量单位。 |
| 减小音量 | `Ctrl + ↓` | `Cmd + ↓` | 每次减少 5 个音量单位。 |
| 静音 / 恢复音量 | `Ctrl + Alt + M` | `Cmd + Alt + M` | 静音时恢复到静音前的音量。 |
| 后退 5 秒 | `←` | `←` | 播放位置向前回退 5 秒。 |
| 前进 5 秒 | `→` | `→` | 播放位置向后前进 5 秒。 |
| 后退 1 秒 | `Shift + ←` | `Shift + ←` | 更精细地回退播放位置。 |
| 前进 1 秒 | `Shift + →` | `Shift + →` | 更精细地前进播放位置。 |
| 喜欢 / 取消喜欢 | `Ctrl + Alt + L` | `Cmd + Alt + L` | 切换当前歌曲的喜欢状态。 |

方向键有两组用途：带主修饰键时切换歌曲或调整音量，不带修饰键时调整当前播放位置。处于输入框、文本域、选择器等可编辑控件中时，应用不会抢占这些按键。

<Callout title="播放位置的边界">
播放位置不会小于 0；歌曲有明确时长时，前进操作也不会超过歌曲末尾。
</Callout>

### 界面操作

| 操作 | Windows / Linux | macOS | 说明 |
| --- | --- | --- | --- |
| 打开搜索 | `Ctrl + K` | `Cmd + K` | 打开全局搜索，并将焦点交给搜索输入框。 |
| 显示 / 隐藏歌词舞台 | `Ctrl + Shift + M` | `Cmd + Shift + M` | 切换歌词舞台的显示状态。 |
| 显示 / 隐藏侧边栏 | `Ctrl + B` | `Cmd + B` | 切换应用侧边栏。 |
| 显示 / 隐藏播放队列 | `Ctrl + J` | `Cmd + J` | 打开或关闭当前播放队列。 |
| 切换全屏 | `Ctrl + Shift + F` | `Cmd + Shift + F` | 切换应用全屏状态。 |
| 打开当前歌曲评论 | `Ctrl + Alt + C` | `Cmd + Alt + C` | 当前存在歌曲时打开评论页。 |
| 打开开发者工具 | `F12` | `F12` | 切换应用开发者工具。 |
| 聚焦歌单搜索 | `Ctrl + Alt + F` | `Cmd + Alt + F` | 仅在歌单作用域中生效。 |

### 快捷键管理

| 操作 | Windows / Linux | macOS | 说明 |
| --- | --- | --- | --- |
| 打开快捷键设置 | `Ctrl + ,` | `Cmd + ,` | 跳转到设置中的快捷键区域。 |
| 显示快捷键帮助 | `Ctrl + /` | `Cmd + /` | 打开当前快捷键帮助面板。 |
| 打开命令面板 | `Ctrl + Shift + P` | `Cmd + Shift + P` | 搜索并执行应用命令。 |
| 关闭当前弹层 | `Esc` | `Esc` | 关闭歌词、搜索、命令面板或其他当前弹层。 |

## 播放控制细节

### 空格键

`Space` 直接切换播放和暂停。它是唯一不需要修饰键的播放控制快捷键；当焦点位于输入控件或可编辑区域时，Scopify 会让浏览器继续处理空格键。

### 静音与恢复

静音操作会记住静音前的音量：

1. 当前音量大于 0 时，按下静音快捷键会保存当前音量并将音量设为 0。
2. 音量为 0 且存在之前的音量记录时，再次按下快捷键会恢复该音量。
3. 直接拖动音量控制不会改变快捷键的语义，但下一次静音会以当前音量作为新的恢复值。

### 跳转播放位置

方向键的播放位置操作支持两种粒度：

- `←` / `→`：以 5 秒为单位跳转；
- `Shift + ←` / `Shift + →`：以 1 秒为单位跳转。

## 界面与作用域

### 全局快捷键

除歌单搜索外，快捷键默认属于全局作用域。它们会在应用窗口内监听，并在当前焦点不是输入控件时执行。

### 歌单作用域

`Ctrl + Alt + F` / `Cmd + Alt + F` 专门用于聚焦歌单搜索。它可以在歌单页面的搜索区域中使用，不会把普通页面上的同一组合键解释成全局操作。

### 可编辑控件

以下控件会优先处理自己的输入：

- `input`；
- `textarea`；
- `select`；
- `contenteditable="true"` 元素。

搜索、命令面板和快捷键管理入口属于例外，因为它们本身就是快捷键交互的一部分。

## 搜索与命令面板

### 全局搜索

按下 `Ctrl + K` / `Cmd + K` 后，Scopify 会打开搜索并自动聚焦搜索输入框。再次执行搜索快捷键可以切换搜索状态。

### 命令面板

按下 `Ctrl + Shift + P` / `Cmd + Shift + P` 打开命令面板。命令面板支持：

- 输入文字过滤命令；
- 使用 `Enter` 执行第一个匹配命令；
- 使用 `Esc` 关闭面板；
- 直接点击命令执行操作；
- 在每条命令右侧查看当前有效快捷键。

命令面板显示的是当前注册表中的快捷键。如果你在设置中修改了绑定，命令面板会显示修改后的按键。

## 自定义快捷键

进入 **设置 → 快捷键** 可以：

- 搜索快捷键命令；
- 录入新的组合键；
- 禁用某条快捷键；
- 恢复单条快捷键默认值；
- 恢复全部默认值。

修改快捷键时，Scopify 会检查与现有命令的冲突。已经被其他命令占用的组合键不能直接分配给当前命令，避免一次按键触发多个操作。

快捷键绑定的结构由以下部分组成：

- `primary`：Windows/Linux 的 `Ctrl` 或 macOS 的 `Cmd`；
- `alt`：`Alt`；
- `shift`：`Shift`；
- `key`：具体按键，例如 `KeyK`、`ArrowLeft`、`Slash`。

单独使用的普通字母不会被默认接受为全局快捷键，以免干扰正常输入。`Space` 和方向键可以作为无修饰键使用。

## 平台显示

快捷键定义使用平台无关的按键代码，显示时再根据平台转换主修饰键：

- Windows / Linux：显示 `Ctrl`；
- macOS / iPhone / iPad：显示 `Cmd`。

因此，组件中的快捷键提示、快捷键帮助面板、命令面板和设置页会保持一致，不需要为每个平台维护两套绑定。

## 快捷键提示

播放器按钮、播放条和歌单操作可以显示对应的 `kbd` 提示。提示读取的是当前有效绑定，而不是固定的默认文本；用户自定义快捷键后，界面中的提示会同步更新。
