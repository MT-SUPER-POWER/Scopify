## 当前路线图

- [ ] 云盘功能。
- [ ] 设备管理区域。
- [ ] 歌单 Tag 编辑能力。
- [ ] 完善系统消息机制。
- [ ] 用户个人信息编辑。
- [ ] 接入昵称检测 API，在修改前提示昵称是否可用。
- [ ] 完善好友能力，包括 Followers 与 Followings 弹窗。
- [ ] 再次播放当前歌曲时允许重新请求，改善部分播放异常。

## 长期提案

- [ ] 本地音乐库管理与离线歌单。
- [ ] 接入 QQ、AMLLDB、酷狗等多源歌词匹配。

路线图表示当前方向，不代表固定交付承诺。新的设计想法、缺陷和实现建议可以通过 [GitHub Issues](https://github.com/MT-SUPER-POWER/Scopify/issues) 讨论。
