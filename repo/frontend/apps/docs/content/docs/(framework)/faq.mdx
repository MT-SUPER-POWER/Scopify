## 客户端安装与运行

### Q：macOS 打开提示“已损坏，无法打开”或“对系统有害”怎么办？

A：这是由于 macOS Gatekeeper 安全机制对未经 Apple 官方付费公证（Notarization）的网络下载应用执行了隔离拦截，**并非安装包真正损坏或包含恶意代码**。请按以下步骤操作：

1. **必须先将应用拖入「应用程序」目录**：打开下载的 `.dmg` 磁盘镜像后，先将 `Scopify.app` 拖入系统的 `/Applications`（应用程序）文件夹中，**切勿直接在只读 DMG 镜像中双击运行**。
2. **终端移除隔离属性（最彻底，推荐）**：打开系统自带的「终端」（Terminal），粘贴并运行以下命令：
   ```bash
   sudo xattr -rd com.apple.quarantine /Applications/Scopify.app
   ```
   输入 Mac 开机密码后回车（输入时终端不会显示字符，直接敲回车）即可完成。
3. **或在系统设置中放行**：若不想使用终端命令，可前往 Mac **「系统设置」→「隐私与安全性」**，向下滑动到「安全性」区域，会看到 _“Scopify 已被阻止使用...”_ 提示，点击右侧的 **“仍要打开”** 并输入密码确认即可。

### Q：macOS 芯片架构该怎么选择？

A：

- **Apple Silicon**：请下载文件名包含 `arm64` 的安装包（例如 `Scopify.Setup.v*.darwin.arm64.dmg`）。
- **Intel 芯片 Mac**：请下载文件名包含 `x64` 的安装包（例如 `Scopify.Setup.v*.darwin.x64.dmg`）。

下错芯片架构会导致应用无法正常启动或运行效率降低，在某些 macOS 版本上也可能被系统误报为损坏。可以在 Mac 屏幕左上角苹果菜单点击「关于本机」确认芯片类型。

## 账号与音乐库

### Q：需要登录才能使用吗？

A：个人音乐库、喜欢的音乐、自建与收藏歌单等账号内容需要登录。私人 FM 的个性化推荐也依赖登录状态。发现内容与搜索是否可用，还取决于当前服务和内容的访问条件。

### Q：登录后没有看到自己的歌单怎么办？

A：先确认当前登录的是预期的网易云音乐账号，再重新进入音乐库。若多个页面都无法加载，优先检查网络与后端连接；自行部署的用户还需要确认后端地址和服务状态，见[部署与运行](/docs/deployment)。

### Q：Scopify 会提供会员歌曲或解锁所有音质吗？

A：可播放的歌曲与音质受账号权限、曲目资源和设备条件影响。选择高音质不会改变账号本身的权限，也不代表每首歌都提供该音质。

## 播放与声音

### Q：在哪里切换音质？

A：从播放栏进入音频设置，或使用 Folia 歌词舞台的控制面板选择音质。可以先用标准音质确认歌曲能正常播放，再选择更高音质。界面与入口见[音质选择](/docs/features/audio#音质选择)。

### Q：播放进度在走，但听不到声音怎么办？

A：依次检查播放栏是否静音、音量是否过低，以及系统音量和实际输出设备。按 `Ctrl + Alt + O`（macOS 为 `Cmd + Alt + O`）打开音频输出面板，确认选中了正在使用的耳机或音箱；设备刚连接时，可以点击刷新设备列表。

如果面板提示当前环境不支持切换输出设备，请通过系统的声音设置选择设备。

### Q：不同歌曲的音量差别很大，怎么调整？

A：可以使用 ReplayGain，按曲目或专辑统一响度。均衡器和声音效果用于进一步调整听感，相关入口见[均衡器与响度](/docs/features/audio#均衡器与响度)。

### Q：私人 FM 的模式控制为什么有时看不到？

A：FM 场景与模式面板只在 FM 播放时显示。先进入私人 FM 并播放，再从播放栏调整模式。普通歌单不会显示这组专用控制。

## 歌词与 Folia

### Q：歌词不匹配，或者比歌曲快 / 慢怎么办？

A：打开歌词控制面板，先检查歌词来源与歌曲匹配；内容正确但时间不同步时，再调整时间轴偏移。更换动画样式主要改变呈现方式，歌词内容与时间问题应在来源、匹配和偏移中处理。

### Q：如何同时显示罗马音与翻译？

A：在 Folia 的副字幕设置中选择「罗马音 + 翻译」。实际显示取决于歌曲是否有对应数据，以及当前歌词模式是否支持；商籁、时计和莫奈已适配双行显示。

### Q：歌词舞台和桌面歌词有什么区别？

A：Folia 歌词舞台在应用中展示完整的封面、背景和动态歌词。桌面歌词是 Electron 桌面端的独立窗口，可以显示在主窗口之外；桌面音乐壁纸则把舞台铺到桌面。网页版不提供这些独立桌面窗口。

## 桌面功能与快捷键

### Q：为什么网页版找不到桌面歌词、托盘或本地 MCP？

A：这些能力由 Electron 宿主提供，需要使用桌面客户端。浏览器内的播放与歌词舞台不等于桌面歌词、系统托盘或本地 MCP 服务。

### Q：桌面音乐壁纸显示在哪个屏幕？

A：多显示器环境下，壁纸覆盖主窗口所在的显示器。可以使用默认快捷键 `Ctrl + Alt + P` 切换，也可以从托盘操作；「桌面动态壁纸」和「悬浮控制器」是两个独立开关。

### Q：除了设置页，还能在哪里切换灵动岛和任务栏歌词？

A：右键系统托盘中的 Scopify 图标，在快捷面板中分别切换桌面歌词、灵动岛和任务栏歌词。任务栏歌词入口仅在 Windows 原生模块可用时显示；动画、字号、显示位置等细项仍在 **设置 → 桌面端** 中调整。桌面歌词开启后，托盘面板还提供锁定与解锁开关。

### Q：关闭主窗口为什么没有退出？

A：关闭窗口后的行为可以在通用设置中调整。若设置为关闭后继续运行，主窗口隐藏不代表客户端已经退出，可以通过托盘继续控制播放。

### Q：快捷键没有反应怎么办？

A：先将焦点移出搜索框或其他输入控件，再确认当前弹层是否限制了快捷键作用域。按 `Ctrl + /` 查看帮助，或到快捷键设置检查绑定与冲突。桌面音乐控制器只响应部分命令，详细说明见[界面与作用域](/docs/shortcuts#界面与作用域)。

## MCP 播放控制

### Q：MCP 连接被拒绝、超时或返回 401 怎么办？

A：连接被拒绝或超时时，先确认桌面端已启用本地 MCP，且服务处于监听状态；端口被占用时需更换端口。返回 `401` 时，重新复制设置页中的客户端配置，尤其是在重新生成令牌后。客户端需要支持 Streamable HTTP，完整步骤见[MCP 播放控制](/docs/mcp)。

### Q：能读取当前歌曲，却不能暂停或切歌？

A：读取与控制分别授权，默认只授予读取。请在桌面设置的「受控能力」中检查相应操作是否开启，同时确认播放器有可控制的播放会话。能够连接服务不等于已获得全部控制权限。

## 反馈问题

### Q：反馈问题时需要提供什么？

A：请附上 Scopify 版本、操作系统、Web / 桌面端、复现步骤、预期结果和实际结果。与某首歌曲有关时，附上歌曲名称或链接；与歌词有关时，补充歌词模式和来源。桌面端可结合日志诊断信息描述问题，提交前请遮盖账号信息、私信、Cookie 和 MCP Bearer 令牌。
