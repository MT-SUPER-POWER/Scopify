## 环境要求

- Bun 1.3.7 或更高版本
- Node.js 20 或更高版本

## 安装依赖

```bash
bun install
```

## 启动方式

```bash
bun run dev          # Web + Electron
bun run dev:web      # 仅 Web
bun run dev:desktop  # 仅 Electron
bun run dev:full     # Web + Electron + 后端
bun run dev:docs     # 文档站
```

Web 与 Electron 的应用源码位于 `repo/frontend/apps/`，共享包位于 `repo/frontend/packages/`；后端位于 `repo/backend/api-enhanced/`，保持独立部署。
