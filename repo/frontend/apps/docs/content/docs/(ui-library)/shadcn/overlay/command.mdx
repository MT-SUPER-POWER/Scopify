提供可搜索的命令、选项或快捷操作列表。上方示例直接渲染 `@scopify/ui` 中的真实组件，可以操作并观察其状态变化。

## 安装

该组件已经通过 shadcn CLI 安装在共享 UI 包。需要与上游重新同步时，在仓库根目录运行：

```bash
cd repo/frontend/packages/ui
bunx shadcn@latest add command
```

CLI 文件属于 `shadcn/` vendor 层；产品特有扩展应放在 `scopify/`，不要直接改写原生实现。

## 导入

```tsx
import {
  Command,
  CommandDialog,
  CommandInput,
  CommandList,
  CommandEmpty,
  CommandGroup,
  CommandItem,
  CommandShortcut,
  CommandSeparator,
} from "@scopify/ui/shadcn/components/command";
```

## 用法

下面是上方交互预览的核心结构。业务状态、路由、请求和 i18n 仍由消费层提供。

```tsx
<Command className="w-full max-w-md rounded-lg border shadow-sm">
  <CommandInput placeholder="搜索命令或音乐" />
  <CommandList>
    <CommandEmpty>没有匹配结果</CommandEmpty>
    <CommandGroup heading="快捷操作">
      <CommandItem>
        <Search /> 搜索音乐 <CommandShortcut>⌘K</CommandShortcut>
      </CommandItem>
      <CommandItem>
        <ListMusic /> 打开播放队列
      </CommandItem>
      <CommandItem>
        <Mic2 /> 开启桌面歌词
      </CommandItem>
    </CommandGroup>
  </CommandList>
</Command>
```

## 常见用法

- 构建命令面板或快速跳转。
- 按组组织命令。
- 为常用操作展示快捷键。

## 使用建议

- 打开后应把焦点移动到浮层，关闭时恢复到触发器。
- 标题与说明用于建立可访问语义；危险操作要明确描述后果。
- 轻量补充用 Popover，聚焦任务用 Dialog，边缘工作区用 Sheet 或 Drawer。

## API 参考

当前模块公开 `Command`、`CommandDialog`、`CommandInput`、`CommandList`、`CommandEmpty`、`CommandGroup`、`CommandItem`、`CommandShortcut`、`CommandSeparator`。实际 props 继承自对应的 Radix primitive 或原生 HTML 元素，并叠加 shadcn 的样式与 slot 约定。

完整的交互模式、可访问性说明和底层 props 请查看 [shadcn/ui Command 命令面板 文档](https://ui.shadcn.com/docs/components/radix/command)；实现差异以本仓库当前 CLI 源码为准。
