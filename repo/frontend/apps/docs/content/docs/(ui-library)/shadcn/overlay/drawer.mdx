从屏幕边缘滑入适合触控交互的内容面板。上方示例直接渲染 `@scopify/ui` 中的真实组件，可以操作并观察其状态变化。

## 安装

该组件已经通过 shadcn CLI 安装在共享 UI 包。需要与上游重新同步时，在仓库根目录运行：

```bash
cd repo/frontend/packages/ui
bunx shadcn@latest add drawer
```

CLI 文件属于 `shadcn/` vendor 层；产品特有扩展应放在 `scopify/`，不要直接改写原生实现。

## 导入

```tsx
import {
  Drawer,
  DrawerPortal,
  DrawerOverlay,
  DrawerTrigger,
  DrawerClose,
  DrawerContent,
  DrawerHeader,
  DrawerFooter,
  DrawerTitle,
  DrawerDescription,
} from "@scopify/ui/shadcn/components/drawer";
```

## 用法

下面是上方交互预览的核心结构。业务状态、路由、请求和 i18n 仍由消费层提供。

```tsx
<Drawer>
  <DrawerTrigger asChild>
    <Button variant="outline">打开播放队列</Button>
  </DrawerTrigger>
  <DrawerContent>
    <DrawerHeader>
      <DrawerTitle>当前播放队列</DrawerTitle>
      <DrawerDescription>接下来将播放 12 首歌曲。</DrawerDescription>
    </DrawerHeader>
    <div className="mx-auto w-full max-w-sm px-4 py-6 text-sm">晴天 · 周杰伦</div>
    <DrawerFooter>
      <Button>开始播放</Button>
    </DrawerFooter>
  </DrawerContent>
</Drawer>
```

## 常见用法

- 在移动端承载轻量任务。
- 从边缘展示上下文内容。
- 保持关闭入口和拖动行为清晰。

## 使用建议

- 打开后应把焦点移动到浮层，关闭时恢复到触发器。
- 标题与说明用于建立可访问语义；危险操作要明确描述后果。
- 轻量补充用 Popover，聚焦任务用 Dialog，边缘工作区用 Sheet 或 Drawer。

## API 参考

当前模块公开 `Drawer`、`DrawerPortal`、`DrawerOverlay`、`DrawerTrigger`、`DrawerClose`、`DrawerContent`、`DrawerHeader`、`DrawerFooter`、`DrawerTitle`、`DrawerDescription`。实际 props 继承自对应的 Radix primitive 或原生 HTML 元素，并叠加 shadcn 的样式与 slot 约定。

完整的交互模式、可访问性说明和底层 props 请查看 [shadcn/ui Drawer 抽屉 文档](https://ui.shadcn.com/docs/components/radix/drawer)；实现差异以本仓库当前 CLI 源码为准。
