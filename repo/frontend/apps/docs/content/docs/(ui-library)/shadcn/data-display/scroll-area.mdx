为溢出内容提供一致的自定义滚动区域。上方示例直接渲染 `@scopify/ui` 中的真实组件，可以操作并观察其状态变化。

## 安装

该组件已经通过 shadcn CLI 安装在共享 UI 包。需要与上游重新同步时，在仓库根目录运行：

```bash
cd repo/frontend/packages/ui
bunx shadcn@latest add scroll-area
```

CLI 文件属于 `shadcn/` vendor 层；产品特有扩展应放在 `scopify/`，不要直接改写原生实现。

## 导入

```tsx
import { ScrollArea, ScrollBar } from "@scopify/ui/shadcn/components/scroll-area";
```

## 用法

下面是上方交互预览的核心结构。业务状态、路由、请求和 i18n 仍由消费层提供。

```tsx
<ScrollArea className="h-52 w-full max-w-sm rounded-lg border p-4">
  <div className="space-y-4">
    {Array.from({ length: 8 }, (_, index) => (
      <div key={index} className="flex items-center justify-between text-sm">
        <span>{String(index + 1).padStart(2, "0")} · 推荐歌曲</span>
        <span className="text-muted-foreground">03:{20 + index}</span>
      </div>
    ))}
  </div>
</ScrollArea>
```

## 组件结构

```text
ScrollArea
```

## 常见用法

- 限制长列表或日志高度。
- 按需展示横向滚动条。
- 不要嵌套多个争抢滚动的区域。

## 使用建议

- 组件只接收整理后的展示数据，获取、缓存和业务计算留在应用层。
- 为加载、空数据和异常状态准备与最终内容尺寸接近的替代视图。
- 复杂数据在窄屏下应提供滚动、折叠或简化视图。

## API 参考

当前模块公开 `ScrollArea`、`ScrollBar`。实际 props 继承自对应的 Radix primitive 或原生 HTML 元素，并叠加 shadcn 的样式与 slot 约定。

完整的交互模式、可访问性说明和底层 props 请查看 [shadcn/ui Scroll Area 滚动区域 文档](https://ui.shadcn.com/docs/components/radix/scroll-area)；实现差异以本仓库当前 CLI 源码为准。
