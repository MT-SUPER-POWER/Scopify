接收较长的多行文本内容。上方示例直接渲染 `@scopify/ui` 中的真实组件，可以操作并观察其状态变化。

## 安装

该组件已经通过 shadcn CLI 安装在共享 UI 包。需要与上游重新同步时，在仓库根目录运行：

```bash
cd repo/frontend/packages/ui
bunx shadcn@latest add textarea
```

CLI 文件属于 `shadcn/` vendor 层；产品特有扩展应放在 `scopify/`，不要直接改写原生实现。

## 导入

```tsx
import { Textarea } from "@scopify/ui/shadcn/components/textarea";
```

## 用法

下面是上方交互预览的核心结构。业务状态、路由、请求和 i18n 仍由消费层提供。

```tsx
<div className="w-full max-w-sm space-y-2">
  <Label htmlFor="preview-description">歌单简介</Label>
  <Textarea id="preview-description" placeholder="写下这个歌单的故事……" />
</div>
```

## 组件结构

```text
Textarea
```

## 常见用法

- 输入多行说明或评论。
- 设置合适最小高度。
- 显示长度限制和校验反馈。

## 使用建议

- 每个控件都要有可访问标签，并在错误时同步 aria-invalid 与错误文本。
- 受控值、校验和提交逻辑由消费层管理，基础组件不耦合具体表单模型。
- 使用单一状态来源，避免同时传入 value 与 defaultValue。

## API 参考

当前模块公开 `Textarea`。实际 props 继承自对应的 Radix primitive 或原生 HTML 元素，并叠加 shadcn 的样式与 slot 约定。

完整的交互模式、可访问性说明和底层 props 请查看 [shadcn/ui Textarea 多行输入框 文档](https://ui.shadcn.com/docs/components/radix/textarea)；实现差异以本仓库当前 CLI 源码为准。
