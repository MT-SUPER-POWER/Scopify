分格接收一次性验证码或短字符序列。上方示例直接渲染 `@scopify/ui` 中的真实组件，可以操作并观察其状态变化。

## 安装

该组件已经通过 shadcn CLI 安装在共享 UI 包。需要与上游重新同步时，在仓库根目录运行：

```bash
cd repo/frontend/packages/ui
bunx shadcn@latest add input-otp
```

CLI 文件属于 `shadcn/` vendor 层；产品特有扩展应放在 `scopify/`，不要直接改写原生实现。

## 导入

```tsx
import {
  InputOTP,
  InputOTPGroup,
  InputOTPSlot,
  InputOTPSeparator,
} from "@scopify/ui/shadcn/components/input-otp";
```

## 用法

下面是上方交互预览的核心结构。业务状态、路由、请求和 i18n 仍由消费层提供。

```tsx
<div className="space-y-3 text-center">
  <Label>输入六位验证码</Label>
  <InputOTP maxLength={6} value={otp} onChange={setOtp}>
    <InputOTPGroup>
      <InputOTPSlot index={0} />
      <InputOTPSlot index={1} />
      <InputOTPSlot index={2} />
    </InputOTPGroup>
    <InputOTPSeparator />
    <InputOTPGroup>
      <InputOTPSlot index={3} />
      <InputOTPSlot index={4} />
      <InputOTPSlot index={5} />
    </InputOTPGroup>
  </InputOTP>
  <p className="text-muted-foreground flex items-center justify-center gap-1 text-xs">
    <AtSign className="size-3" /> 已发送到你的邮箱
  </p>
</div>
```

## 组件结构

```text
InputOTP
├── InputOTPGroup
├── InputOTPSlot
├── InputOTPSeparator
```

## 常见用法

- 按位输入验证码。
- 通过 Group 和 Separator 表达分段。
- 受控处理粘贴、提交和错误状态。

## 使用建议

- 每个控件都要有可访问标签，并在错误时同步 aria-invalid 与错误文本。
- 受控值、校验和提交逻辑由消费层管理，基础组件不耦合具体表单模型。
- 使用单一状态来源，避免同时传入 value 与 defaultValue。

## API 参考

当前模块公开 `InputOTP`、`InputOTPGroup`、`InputOTPSlot`、`InputOTPSeparator`。实际 props 继承自对应的 Radix primitive 或原生 HTML 元素，并叠加 shadcn 的样式与 slot 约定。

完整的交互模式、可访问性说明和底层 props 请查看 [shadcn/ui Input OTP 验证码输入 文档](https://ui.shadcn.com/docs/components/radix/input-otp)；实现差异以本仓库当前 CLI 源码为准。
