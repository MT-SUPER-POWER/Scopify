在分段数据或页面之间前后跳转。上方示例直接渲染 `@scopify/ui` 中的真实组件，可以操作并观察其状态变化。

## 安装

该组件已经通过 shadcn CLI 安装在共享 UI 包。需要与上游重新同步时，在仓库根目录运行：

```bash
cd repo/frontend/packages/ui
bunx shadcn@latest add pagination
```

CLI 文件属于 `shadcn/` vendor 层；产品特有扩展应放在 `scopify/`，不要直接改写原生实现。

## 导入

```tsx
import {
  Pagination,
  PaginationContent,
  PaginationLink,
  PaginationItem,
  PaginationPrevious,
  PaginationNext,
  PaginationEllipsis,
} from "@scopify/ui/shadcn/components/pagination";
```

## 用法

下面是上方交互预览的核心结构。业务状态、路由、请求和 i18n 仍由消费层提供。

```tsx
<Pagination>
  <PaginationContent>
    <PaginationItem>
      <PaginationPrevious href="#previous" />
    </PaginationItem>
    {[1, 2, 3].map((page) => (
      <PaginationItem key={page}>
        <PaginationLink href={`#page-${page}`} isActive={page === 2}>
          {page}
        </PaginationLink>
      </PaginationItem>
    ))}
    <PaginationItem>
      <PaginationNext href="#next" />
    </PaginationItem>
  </PaginationContent>
</Pagination>
```

```text
Pagination
├── PaginationContent

├── PaginationEllipsis
```

## 常见用法

- 在数据页之间前后跳转。
- 标记当前页。
- 页数很多时使用省略项而不是渲染全部页码。

## 使用建议

- 当前项、焦点项和禁用项必须在视觉与语义上都能区分。
- 路由决策留在应用层，基础组件只接收链接、状态与回调。
- 保证完整键盘路径，并避免将主要入口只放进隐藏菜单。

## API 参考

当前模块公开 `Pagination`、`PaginationContent`、`PaginationLink`、`PaginationItem`、`PaginationPrevious`、`PaginationNext`、`PaginationEllipsis`。实际 props 继承自对应的 Radix primitive 或原生 HTML 元素，并叠加 shadcn 的样式与 slot 约定。

完整的交互模式、可访问性说明和底层 props 请查看 [shadcn/ui Pagination 分页 文档](https://ui.shadcn.com/docs/components/radix/pagination)；实现差异以本仓库当前 CLI 源码为准。
