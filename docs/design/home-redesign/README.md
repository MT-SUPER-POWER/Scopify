# 首页排版提案

## 第二版：官方排行榜

用户仅认可第一版的播客卡片，其他首页改动不作为实施依据。`official-charts-v2.png` 用内置 ImageGen 单独探索官方排行榜：两列两行、左侧大榜单封面、右侧三首歌曲的歌名与歌手分层，下方保留认可的播客卡片。

已实际请求本地后端 `GET /toplist/detail`，四个榜单公开摘要保存在 `official-charts-data.json`。摘要提供榜单封面、更新信息和前三首歌名/歌手，不提供单曲封面及排名涨跌。生成提示使用这些真实文字，要求保留应用外框与播客区；图片仍有生成文字误差，封面为概念重绘，实施应使用接口原始封面与文案。此版未改应用代码。

本目录保存当前首页长截图和 ImageGen 排版概念稿，仅用于视觉讨论，尚未修改首页实现。

- `home-current-long.png`：从当前运行的首页分段截图拼接，保留全部默认展开的模块。固定侧栏与播放器仅保留一次；侧栏下方的深色区域为长图拼接画布，不代表实际窗口高度。
- `home-00.png` 至 `home-04.png`、`capture-parts.json`：原始分段与滚动位置。
- `home-redesign-v1.png`：内置 ImageGen 生成的新版概念稿。

## 排布方向

1. 问候与两行快捷入口，银灰氛围渐变仅留在顶部。
2. 为你推荐：统一封面尺寸，去掉常驻播放量徽标和厚重外框。
3. 新歌速递：两列三行，强调歌名、歌手和时长的对齐。
4. 新碟上架：复用歌单网格，音乐内容连续浏览。
5. 精选活动：降低高度，改为等大的横幅，避免中心放大轮播抢占注意力。
6. 官方排行榜：四块等宽榜单，各保留前三首。
7. 推荐播客声音：三列两行横向卡片，区分于单曲列表。
8. 推荐歌手：圆形头像收尾。

保留现有侧栏、全局搜索和播放器。以封面构成色彩，绿色只用于可操作控件。生成图中的文案、封面及细节属于概念表达，实施时使用现有真实数据。
