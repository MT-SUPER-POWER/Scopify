## 五项视觉核对

- 字体：复用 Scopify 字体，标题 30–42px/800，设备标题 15px/600，选中设备 20px/650；列表元信息为次级灰色。生成稿中文字不是可复用字体资源，以现有应用字族为准。
- 排布：横向四设备共享场景，绿线标识选择；下方横向信息条与轻量列表；额度移至标题右侧；无重复面包屑。窄窗口允许展示台自身横向滚动，信息条自动换行，未改变全局播放器布局。
- 色彩：石墨灰与深绿素材，正文/边框/强调色使用主题 token；暗色摄影场景维持参考方向。
- 图像：四份真实 RGBA 独立设备图和一份 RGB 背景，均由 ImageGen 引用选定设计生成并原样入库。未使用 CSS/SVG 绘制硬件；缩略图复用原素材，透明背景没有矩形底。
- 内容：可编辑 UI 文案由组件渲染，明确示例数据；不引入生成稿中没有接口依据的首次登录、在线状态。当前设备专有改名入口保持禁用，其余设备提供详情。

## 已操作的局部交互

- 点选 iPhone 更新绿色选择线与下方名称/平台/活动信息。
- 最近活动切换为五条按示例时间顺序排列的记录，返回所有设备恢复展示台。
- 展开较早记录增加 Windows PC、pc，再收起。
- 手机详情抽屉打开/关闭，展示平台、活动、地区与登录方式；下线入口禁用。
- 页面控制台有既有 HeaderSearch 热搜请求 Network Error 和开发期 Fast Refresh 完整刷新提示；未见设备页组件渲染异常。未扩展处理全局网络问题。

## 可接受差异与余项

- [P3] 独立生成硬件与参考中的具体机型边框、金属亮度不完全相同；构图与材质方向一致。
- [P3] 窄窗口下较长设备名可能换行；不截断名称，展示台可水平滚动。
- 没有运行构建、lint、类型检查或自动测试。此次验证只覆盖用户请求的视觉落实与本地预览交互；真实设备数据和写操作不在本轮范围。
