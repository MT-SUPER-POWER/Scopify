# Adopt AGPL-3.0 for Folia-derived Scopify releases

Scopify will distribute future releases containing Folia-derived lyric or desktop-lyric code under AGPL-3.0, rather than retain MIT as the project-level license. This permits direct adaptation of Folia's AGPL-3.0 implementation while preserving the source-access and notice obligations that accompany it.

## Consequences

- Existing MIT releases remain available under their original grant; the new license governs future Folia-derived releases.
- The distributed application must retain the appropriate Folia copyright and AGPL notices and make its corresponding source available.
- Web deployments of a Folia-derived Scopify build must offer their users access to the corresponding source.
