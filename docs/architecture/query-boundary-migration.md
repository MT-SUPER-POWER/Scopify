## 首批验证范围

- 定向测试覆盖首次失败、空结果、缓存刷新失败与恢复、同一业务单元备用来源、账号 key 隔离。
- 首页浏览器检查确认各栏目与应用外壳渲染；不存在的 MV 请求返回 404 时只替换主内容区，顶栏、侧栏和播放栏保留。真实断网、重试成功、登录账号切换及媒体切换仍需专门验证。
- Git hooks 覆盖架构检查、暂存文件格式与 Web ESLint；不等同于全仓 typecheck、构建或端到端验证。

后续按领域逐批提交。每批删除被替代的状态辅助器、过期类型与实现耦合测试，避免同时保留两套错误处理路径。
